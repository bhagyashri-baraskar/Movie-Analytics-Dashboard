# Movie Analytics Dashboard (Interactive Dashboard using SQL Server & Power BI)

## Project Objective
The objective of this project is to analyze historical movie data to understand movie performance, revenue generation, profit margins, audience ratings, and ROI.  
This dashboard helps stakeholders identify top-performing movies, studios, and industries, enabling data-driven decisions in movie production and distribution.

## Dataset Used
[movies-db-1.xlsx](https://github.com/bhagyashri-baraskar/Movie-Analytics-Dashboard/blob/main/movies-db-1.xlsx)

## The dataset contains:
• Movie titles  
• Studios and industries  
• Language information  
• Revenue and profit margin  
• IMDb ratings  
• Return on Investment (ROI)

## Key Business Questions (KPIs)
• What is the total revenue and total number of movies?  
• Which movie has the highest ROI?  
• What is the average IMDb rating across all movies?  
• Which languages contribute the most to revenue?  
• Which studios generate the highest revenue?  
• How do ratings and profit margins vary across industries?

## Process
• Checked the dataset for missing values and inconsistencies  
• Cleaned and standardized data types and formats  
• Created calculated fields and KPIs for revenue, profit margin, ROI, and ratings  
• Built visuals using charts, tables, and slicers  
• Designed an interactive dashboard with filters for Language, Studio, Rating Range, and Industry

## Dashboard Features
• KPI cards showing Total Movies, Total Revenue, Average Rating, Profit Margin, and Top ROI Movie  
• Language-wise movie distribution visualization  
• Studio-wise revenue comparison  
• Industry-wise analysis of ratings and profit margins  
• Interactive slicers for dynamic filtering

## Project Insights
• English movies dominate the dataset, followed by Hindi and Telugu movies  
• Government studios generate the highest total revenue  
• Hollywood movies have higher average ratings, while Bollywood movies show stronger profit margins  
• High ratings do not always guarantee high revenue or ROI  
• Movie performance depends on language, studio, and industry

## Conclusion
This analysis highlights key drivers of movie success, including studio performance, language popularity, and industry trends.  
By focusing on high-ROI movies and strong-performing studios, stakeholders can optimize investment, production, and marketing strategies.  
The dashboard provides a clear, data-driven view to support strategic planning and performance evaluation.
